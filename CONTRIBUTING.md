# Contributing to OpenSource Compass

Thank you for your interest in contributing to **OpenSource Compass**! This project aims to empower students and beginner developers to make their first open-source contributions.

## How Can I Contribute?

### 1. Reporting Bugs
- Search existing issues to verify the bug hasn't already been reported.
- Open a new issue with a clear title, description, steps to reproduce, and expected behavior.

### 2. Suggesting Enhancements
- Open an issue explaining your proposed feature, why it is beneficial, and how it could be implemented.

### 3. Submitting Pull Requests
1. **Fork the Repository**: Click the 'Fork' button on GitHub.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/your-username/opensource-compass.git
   cd opensource-compass
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make Your Changes**: Ensure your code is clean, readable, and well-tested.
5. **Commit Your Changes**:
   ```bash
   git commit -m "Add amazing feature"
   ```
6. **Push to Your Fork**:
   ```bash
   git push origin feature/amazing-feature
   ```
7. **Open a Pull Request**: Provide a clear summary of your changes and reference any related issues.

## Style Guide
- **Frontend**: Follow React best practices, keep components modular, and maintain CSS dark/light theme consistency.
- **Backend**: Adhere to PEP 8 standards, use type hints in FastAPI, and include Pytest test coverage for new endpoints.

Thank you for helping make open source accessible for everyone!
